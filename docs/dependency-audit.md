## 版本与下载量（调整前）

- **声明版本**来自 `package.json`，**锁定版本**来自 `pnpm-lock.yaml`。
- **npm 默认版本**由维护者的 `latest` 标签决定，本次均与最新稳定版一致。加粗表示有更新。
- **热门版本**为官方近七天下载最多的稳定版，下载量不等于用户数，也不作为降级依据。

数据来自 npm 官方源；项目使用 npmmirror，可能存在同步延迟。下载接口不提供统计起止日期。
